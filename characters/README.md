# Fichas de personajes

Una ficha por personaje que habla (`nombre.md`). Si el juego tiene líneas que dicen varios personajes distintos (voces genéricas, personalidades), una ficha por voz (`voz-nombre.md`). Las escribe el perfilador a partir del original y las aprueba el usuario. Sin spoilers: solo cómo habla cada uno, nunca qué le pasa en la historia.

## Plantilla

```markdown
# Nombre

- **Género:** (como lo marca el juego; si no se sabe, «pendiente»)
- **Trato:** tú o usted, y con quién (STYLE E-30)
- **Registro:** casual, formal, de época...
- **Muletillas y tics:** (según el original)
- **Groserías:** cuáles y con qué intensidad
- **Ejemplos:** dos o tres claves de líneas que lo muestran
- **Fuente:** las claves leídas para armar la ficha
```

## Voces compartidas

Si una misma línea la dicen personajes de distinto género (STYLE E-41), la ficha de esa voz describe el registro, las muletillas y cómo trata al jugador, y nunca marca el género de quien habla.
